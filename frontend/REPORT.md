# Отчёт о проделанной работе: Room&Assets Management Application

## Обзор проекта

**Название проекта:** Room&Assets  
**Описание:** Веб-приложение для управления помещениями и активами. Позволяет просматривать каталог помещений, управлять бронированиями и настройками. Данные хранятся локально в IndexedDB браузера.

**Цель проекта:** Создать современное одностраничное приложение (SPA) с возможностью контейнеризации для удобного развертывания.

## Архитектура и технологии

### Основные технологии:
- **Frontend Framework:** React 19 с TypeScript
- **Build Tool:** Vite 7
- **UI Library:** Material-UI (MUI) 7
- **Стилизация:** Emotion (CSS-in-JS)
- **Локальное хранилище:** IndexedDB (нативный API браузера)
- **HTTP-клиент:** Axios
- **Мокирование API:** MSW (Mock Service Worker) - для симуляции API в разработке
- **ORM:** Prisma (для потенциального подключения к базе данных)
- **Контейнеризация:** Docker с multi-stage сборкой

### Структура проекта:
```
src/
├── components/          # Переиспользуемые UI компоненты
│   ├── Header/         # Навигационная панель
│   ├── RoomsTable/     # Таблица помещений
│   ├── BookingForm/    # Форма бронирования
│   ├── ResourceForm/   # Форма ресурсов
│   └── Button/         # Кастомная кнопка
├── pages/              # Страницы приложения
│   ├── Home/          # Главная страница (каталог)
│   ├── Bookings/      # Управление бронированиями
│   └── Settings/      # Настройки
├── utils/              # Утилиты
│   └── indexedDB.ts   # Класс для работы с IndexedDB
├── types/              # TypeScript типы
└── stores/             # Состояние приложения (если используется)
```

## Реализованные функции

### 1. Навигация
- Реактивная навигационная панель с кнопками для переключения между разделами
- Поддержка активного состояния для текущей страницы
- Интеграция с React state для управления маршрутизацией

### 2. Управление помещениями
- Отображение списка помещений в табличном виде
- Локальное хранение данных в IndexedDB
- Поддержка операций CRUD (создание, чтение, обновление, удаление)

### 3. Управление бронированиями
- Форма для создания новых бронирований
- Просмотр существующих бронирований
- Интеграция с данными помещений

### 4. Управление ресурсами
- Формы для добавления и редактирования ресурсов
- Связь ресурсов с помещениями

### 5. Локальное хранилище
- IndexedDB для персистентного хранения данных
- Асинхронные операции с базой данных
- Поддержка объектных хранилищ для разных типов данных

## Docker-контейнеризация

### Multi-stage Dockerfile:
1. **deps:** Установка зависимостей
2. **dev:** Режим разработки с hot reload
3. **build:** Сборка production версии
4. **prod:** Nginx сервер для статических файлов

### Docker Compose файлы:
- `docker-compose.dev.yml`: Для разработки (порт 5173)
- `docker-compose.yml`: Для production (порт 80)

## Процесс разработки

## Запуск и использование

### Локальный запуск:
```bash
npm install
npm run dev
```
Приложение будет доступно на `http://localhost:5173`

### Запуск в Docker (разработка):
```bash
docker-compose -f docker-compose.dev.yml up --build
```

### Production сборка:
```bash
docker-compose up --build
```
Приложение будет доступно на `http://localhost:80`
